# Звіт: STT Quality Spike

**Дата:** 2026-03-30
**Мета:** Оцінити провайдерів STT для транскрибації українськомовних навчальних відео
**Контекст:** Поточний pipeline використовує Gemini Vision для аналізу відео, який видає низькоякісну транскрипцію українською (суржик). STT-ланцюжок має його замінити.

## Протестовані провайдери

### 1. Deepgram Nova-3

- **API:** `POST https://api.deepgram.com/v1/listen`
- **Модель:** `nova-3`
- **Параметри:** `language=uk, punctuate=true, paragraphs=true, smart_format=true`

### 2. ElevenLabs Scribe

- **API:** `POST https://api.elevenlabs.io/v1/speech-to-text`
- **Модель:** `scribe_v1`
- **Параметри:** `language_code=ukr`

### 3. OpenAI Whisper

- **API:** `POST https://api.openai.com/v1/audio/transcriptions`
- **Модель:** `whisper-1`
- **Параметри:** `language=uk, response_format=verbose_json`

### 4. OpenAI GPT-4o Mini Transcribe

- **API:** `POST https://api.openai.com/v1/audio/transcriptions`
- **Модель:** `gpt-4o-mini-transcribe`
- **Параметри:** `language=uk, response_format=json`

### 5. Sonix

- **API:** `POST https://api.sonix.ai/v1/media` (async — завантаження, опитування, отримання)
- **Модель:** За замовчуванням (не обирається)
- **Параметри:** `language=uk`
- **Примітка:** Асинхронний API — завантажити файл, опитувати `GET /v1/media/<id>` до `status=completed`, потім `GET /v1/media/<id>/transcript`

## Детальна оцінка

### Deepgram Nova-3

**Переваги:**
- Надзвичайно швидкий (5.4 сек на 10.5 хв аудіо — 117x realtime)
- Хороший показник confidence (0.969)
- Деякі технічні терміни розпізнає коректно (STR, INT)

**Недоліки:**
- Найгірша якість українською з чотирьох
- Спотворює складні українські слова ("тлумаче словоникада", "питанню")
- Помиляється у займенниках ("��ого" замість "Я вас")
- Втрачає контекст на змішаному українсько-англійському контенті

**Висновок:** Швидкий і дешевий, але не підходить як основний STT для українського навчального контенту. Можна використовувати як швидкий fallback.

### ElevenLabs Scribe

**Переваги:**
- Найкраща загал��на якість українською
- Зберігає структуру м��влення: паузи, хезитації, самовиправлення
- Найточніший для складних українських фраз
- Коректно обробляє технічні терміни в контексті
- Природна пунктуація з "--" для обірваних думок

**Недоліки:**
- С��редній за швидкістю (26 сек, але все ще 24x realtime)
- Транс��ітерує ідентифікатори коду кирилицею ("стр", "інт", "флот" замість STR, INT, FLOAT)
- Використовує `scribe_v1` (v2 орієнтований на realtime, інший API)

**Висновок:** Найкраща якість для нашого use case. Проблему транслітерації можна вирішити post-processing (regex заміна відомих кириличних форм на латинські оригінали).

### OpenAI Whisper

**Переваги:**
- Найкраще збереження латинських технічних термінів (STR, INT, FLOAT, traceback, frame)
- Хороша загальна якість українською
- Повертає детальні timestamps на рівні сегментів (167 сегментів)
- Стабільний, відомий API

**Недоліки:**
- Найповільніший (41.7 сек)
- Спотворює деякі українські фрази ("сломачена слоникада")
- Помиляється в деяких термінах ("качівну" замість "качину")
- Найдорожчий за хвилину

**Висновок:** Замінений на GPT-4o Mini Transcribe, який швидший, дешевший і якісніший.

### OpenAI GPT-4o Mini Transcribe

**Переваги:**
- Найкраще збереження латинських технічних термінів — всі правильно (STR, INT, FLOAT, int, float, bool, decimal, fraction, number, type, id, traceback, frame, bytes, ByteArea)
- Хороша загальна якість українською
- Швидкий (18.9 сек — 34x realtime)
- Найдешевший варіант ($0.003/хв)
- Використовує той самий OpenAI API ключ — додаткова реєстрація не потрібна

**Недоліки:**
- Спотворює деякі українські фрази ("словничний словника" замість "тлумачного словника")
- Не розпізнав "качину типізацію" — замість цього "як чінити типізацію"
- Не зберігає паузи та хезитації
- Не підтримує `verbose_json` формат відповіді (немає timestamps сегментів)
- Пише "Python" замість "Пайтон" (може бути бажаним або ні залежно від контексту)

**Висновок:** Відмінне доповнення до ElevenLabs. Найкраще збереження технічних термінів + найнижча ціна. Сильний кандидат на основного або вторинного провайдера.

### Sonix

**Переваги:**
- Відмінна якість українською — правильно транскрибує складні фрази ("з тлумачного словника", "качина типізація")
- На рівні з ElevenLabs для загальної української прози (найкращі два провайдери для української мови)
- Speaker diarization з коробки (коректно визначив "Speaker 1")
- Word-level timestamps з точним таймінгом у JSON форматі
- Самооцінка якості (quality score: 94.16)

**Недоліки:**
- **Надзвичайно дорогий** — $5–10/год проти $0.18–0.36/год у інших (у 25–55 разів дорожче)
- Найповільніший провайдер (65 сек, 9.8x realtime) — асинхронний API додає затримки
- Найгірша обробка технічних термінів — "INT" почуто як "інде" (українське слово), ієрархія типів спотворена ("її" замість int, "був" замість bool)
- Транслітерує всі ідентифікатори коду кирилицею (як ElevenLabs, але з гіршою точністю)
- Асинхронний API (завантаження → опитування → отримання) — складніша інтеграція
- Водяний знак на транскриптах trial-акаунту
- "bytes" → "баштовий", "ByteArray" → "бейт Ілія", "traceback" → "1с бек" — сильно спотворені технічні терміни

**Висновок:** Хороша якість української прози (порівнянна з ElevenLabs), але найгірше розпізнавання технічних термінів із усіх п'яти провайдерів, у поєднанні з ціною у 25–55 разів вищою. **Не підходить для нашого use case** — навчальний програмістський контент потребує надійного розпізнавання технічних термінів, а ціна заборонна.

## Рекомендація

### Основний: ElevenLabs Scribe
Найкраща загальна якість для українського навчального контенту. Транслітерація кодових термінів кирилицею — вирішувана проблема post-processing.

### Вторинний: GPT-4o Mini Transcribe
Найкраще збереження технічних термінів (латиниця), найдешевший ($0.003/хв), хороша швидкість (34x realtime). Відмінне доповнення до ElevenLabs — сильний саме там, де ElevenLabs слабкий.

### Fallback: Deepgram Nova-3
Найшвидший варіант (117x realtime). Нижча якість для української, але достатня для простого контенту або коли важлива швидкість.

### Застарілий: OpenAI Whisper
Замінений на GPT-4o Mini Transcribe за всіма метриками (швидший, дешевший, якісніший). Немає причин використовувати Whisper-1.

### Не рекомендовано: Sonix
Хороша якість української прози (на рівні ElevenLabs), але найгірше розпізнавання технічних термінів і ціна у 25–55 разів вища. Асинхронний API ускладнює інтеграцію. Не підходить для програмістського навчального контенту.

### Опціонально (ще не тестовано): Soniox
Заплановано для подальшої оцінки. API-ключ в процесі отримання.
