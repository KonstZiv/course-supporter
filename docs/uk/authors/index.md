# Для авторів

Цей розділ — для авторів курсів: як підготувати курс на платформі до роботи студентів.

- [Тести](tests.md) — як створити тест у програмі автора, перевірити його моделлю й опублікувати; як
  рахується бал; як записати тест у файлі.
- [Тести й критерії через API](api.md) — довідка для платформ шкіл, які готують курс запитами, без
  програми автора: запити, відповіді й коди відмов.

Сторінки про структуру курсу, матеріали, завдання й описи розділів — у підготовці.
