# Сховище — база й об'єкти

Модуль тримає шар доступу до PostgreSQL і до S3-сумісного сховища (на проді Backblaze B2, у
розробці SeaweedFS).

## Частини

| Модуль | Що робить |
|---|---|
| `orm.py` | Усі моделі SQLAlchemy; м'яке видалення — `deleted_at` (`SoftDeleteMixin`) |
| `*_repository.py` | Доступ до таблиць: один репозиторій на сутність; репозиторій робить `flush`, `commit` — справа викликача |
| `cascade.py` | Каскад м'якого видалення: скасування завдань → інвалідація хешів → очищення полів → `deleted_at` |
| `s3.py` | Асинхронний клієнт S3: завантаження, підписані посилання, перелік, видалення |
| `orphans.py` | Осиротілі об'єкти відра матеріалів: знайти й поставити в наявне прибирання (Б-2, `scripts/storage_admin.py`, сторінка команди — `orphans.md`) |
